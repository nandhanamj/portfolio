# Nandhana M J Portfolio

A modern, responsive portfolio website built with HTML, CSS, JavaScript, and Bootstrap 5.

## Features
- Responsive hero section with animated typing effect
- About, skills, experience, projects, certifications, achievements, interests, and contact sections
- Glassmorphism styling with a professional blue and white palette
- Light and dark theme toggle
- Smooth scrolling, reveal animations, and back-to-top button
- SEO-friendly structure and accessible navigation

## Files
- index.html - Main page structure
- style.css - Visual styling and responsive layout
- script.js - Interactivity, animations, and theme switching
- assets/images - Images
- assets/files/NMJ_Resume.pdf - Downloadable resume
